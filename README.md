# AWS Cloud Practitioner Hands-On Labs

This repository documents my **21 practical labs** while preparing for the **AWS Certified Cloud Practitioner (CLF-C02)** certification.

The goal is to build a strong foundation in AWS by implementing core services hands-on, following best practices in security, networking, storage, compute, and observability.

## 🎯 Learning Objectives

- Understand and apply the **Shared Responsibility Model**
- Implement the **Principle of Least Privilege** using IAM
- Provision and secure core AWS services
- Build basic fault-tolerant and scalable architectures
- Document infrastructure configurations professionally

---

## 🛠️ Technologies & Concepts Applied

- **IAM**: Users, Groups, Roles, Custom Policies & Least Privilege
- **Compute**: EC2 Instances, Security Groups, Key Pairs, User Data
- **Storage**: Amazon S3 with Versioning and Lifecycle Policies
- **Networking**: VPC, Public/Private Subnets, NAT Gateway
- **Databases**: Amazon RDS (Secure deployment and connectivity)
- **Observability**: CloudWatch Alarms, Dashboards, and Logs
- **High Availability**: Elastic Load Balancing + Auto Scaling Groups
